Sideload gterm with AltStore or SideStore

A Ghostty-powered iOS terminal that connects over SSH — installed from one shared source, signed on-device with your own Apple ID.

Add to AltStore → Add to SideStore →
Source URL: https://madeye.github.io/gterm/altstore.json
Both stores read the same source. Tap a button on iOS with the corresponding app installed; on desktop, copy the URL and add it under Sources → +.

Install steps

  1. Install AltStore or SideStore on your iPhone (whichever you prefer — SideStore doesn't need a Mac companion).
  2. Tap the matching Add to … button above on the device, or open the store and paste https://madeye.github.io/gterm/altstore.json under Sources → +.
  3. Find gterm in the source and tap Free to install.
  4. The store re-signs the app with your Apple ID; trust the developer in Settings → General → VPN & Device Management.

AltStore vs. SideStore

  • AltStore pairs with a Mac/Windows companion (AltServer) that refreshes the signature when both are on the same Wi-Fi.
  • SideStore refreshes on-device — no companion needed. It runs an embedded server and enables JIT on supported builds.
  • Both read this exact source, install the same .ipa, and sign it with your own Apple ID.

About sideloading

The store re-signs the app with your own Apple ID, which means it expires every 7 days on a free Apple ID (refresh in AltStore/SideStore over Wi-Fi to renew) or yearly on a paid Apple Developer account. The TestFlight build is a smoother path if you prefer — join here.

Privacy

gterm collects no personal data. SSH credentials and imported keys are stored only in the on-device Keychain. AI features are off until you configure a provider; when enabled they talk directly to that provider with your own API key. See the full privacy policy.
